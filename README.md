# ![logo](https://github.com/Kostya0Sim/Iron-Chests-DM/blob/main/pack.png) Iron Chests: DM
This resource pack changes the appearance of the [Iron Chests](https://www.curseforge.com/minecraft/mc-mods/iron-chests) GUI to the darker and less saturated tones like in a [Default Dark Mode](https://www.curseforge.com/minecraft/texture-packs/default-dark-mode) resource pack.
